01The idea

A shared noticeboard
for campus life.

Campus Event Hub is a simple place to discover student events, from a one-hour workshop to a late-night film screening. Instead of chasing posters and scattered messages, students can browse one clear calendar and decide what sounds like them.

This project demonstrates how a small Node.js server can deliver a useful, multi-page website. The event list is also available as JSON, giving another program a way to read the same information.
